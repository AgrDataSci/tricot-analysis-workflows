# Methodological decision records

Each file sets out the default approach for one topic, the alternatives, and the limits of interpretation. Read the relevant record before using any code in `use-cases/` or `archive/`.

## Core principle

Select methods according to the scientific question, statistical defensibility and operational usefulness. Preserve historical provenance and distinguish established approaches, context-dependent alternatives and research hypotheses.
